# Fairmake Material Certs fixtures

Fictional receipts, certificate values and purchase specs. Spec values are illustrative, not taken from any standard.

- `receipts.csv`, `certs.csv`, `specs.json`: a bar receipt in spec; one below the tensile minimum (RC-2002); one with no certificate (RC-2003); a plate certificate for another heat (RC-2004); a plate certificate that does not report yield (RC-2005); a casting certificate not on file (RC-2006); screws that need no certificate; a gasket with no spec.
- `specs-relaxed.json`: looser specs.
- `exports/epicor-receipts.csv`: Epicor-style receipt lines. Written from knowledge of the export, not checked against a live system.
