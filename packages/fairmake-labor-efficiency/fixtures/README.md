# Fairmake Labor Efficiency fixtures

Fictional labor tickets and completions; every employee name is made up.

- `labor.csv`, `earned.csv`: CNC on target; WELD below target with high indirect time; ASSY above the ceiling with hours on a work order that completed nothing; PAINT on target; SAW completed a work order with no hours clocked.
- `settings.json`, `settings-wide.json`: default and wider targets.
- `exports/jobboss-labor-detail.csv`: JobBOSS-style labor detail. Written from knowledge of the export, not checked against a live system.
