# Fairmake Cycle Counts fixtures

Fictional cycle count lines, unit costs in US dollars.

- `counts.csv`: A items short or over past tolerance (CC-1002, CC-1008), a B item short on one count and varying again on another (BAR-4140), a C item short by percentage but small in value (CC-1005), a line not counted (CC-1006), negative system stock (CC-1007) and clean lines.
- `settings.json`, `settings-loose.json`: default and looser tolerances.
- `exports/fishbowl-cycle-count.csv`: Fishbowl-style cycle count columns. Written from knowledge of the export, not checked against a live system.
